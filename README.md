Health and Hygiene Website

This is a simple multi-page website created to spread awareness about health and hygiene.

Topics Covered

- Personal Hygiene
- Healthy Habits
- Disease Prevention

Technologies Used

- HTML
- CSS

Website Features

- Simple and user-friendly design
- Separate pages for each health topic
- Relevant images for better understanding
- Navigation links between pages
- Responsive image layout

Project Structure

- "index.html" – Home Page
- "hygiene.html" – Personal Hygiene Page
- "habits.html" – Healthy Habits Page
- "prevention.html" – Disease Prevention Page
- "style.css" – Website styling
- "images/" – Images used in the website

Purpose

The purpose of this project is to provide basic information and create awareness about maintaining good health and hygiene through simple and easy-to-understand content.
